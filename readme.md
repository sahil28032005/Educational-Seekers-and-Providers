# Educational Seekers Platform

![Educational Seekers Logo](./vite-project/public/logo.png)

## 🚀 Overview

Educational Seekers is a comprehensive platform designed to connect students, educators, and professionals in a collaborative learning environment. The platform facilitates networking, group collaboration, and knowledge sharing to enhance the educational experience.

## ✨ Features

### 👥 Community Networking
- Connect with peers, mentors, and educators
- Send and manage connection requests
- Build your professional network

### 👨‍👩‍👧‍👦 Groups & Collaboration
- Create and join interest-based groups
- Collaborate on projects and discussions
- Share resources within your groups
- Public and private group options

### 🔍 Smart Discovery
- Find connections based on interests and skills
- Discover relevant groups
- Personalized suggestions based on your profile

### 📊 Dashboard
- Personalized user dashboard
- Track your connections and activities
- Access your groups and courses

## 🛠️ Technology Stack

- **Frontend**: React.js, Vite, TailwindCSS, ShadCN UI
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL with Prisma ORM
- **Real-time Communication**: Kafka
- **Authentication**: JWT-based auth system

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- PostgreSQL
- Kafka (for real-time features)
